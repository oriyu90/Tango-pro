# CSV形式仕様

Tango pro v1.2.0のAndroid版とmacOS版で共通に扱う単語帳形式です。

## 文字コードと行

- 文字コード: UTF-8（先頭BOMの有無は不問）
- 改行: LFまたはCRLF
- 上限: 100,000レコード
- 空行: 無視
- ヘッダー: 不要。先頭行から単語として読み込む

## 列

| 列 | 内容 | 必須 |
| --- | --- | --- |
| 1 | 学習対象の語句（英語または中国語） | 必須 |
| 2 | 日本語訳 | 必須 |
| 3 | タグ、品詞、カテゴリ | 任意 |
| 4 | 発音記号、ピンイン、読み方 | 任意 |

5列目以降は現行版では使用しません。1列目または2列目が空の行は有効な単語として取り込みません。

```csv
apple,りんご,名詞,æpl
run,走る,動詞,rʌn
你好,こんにちは,挨拶,nǐ hǎo
```

## 引用符

RFC 4180相当の引用規則に対応します。カンマ、改行、二重引用符を含む値は二重引用符で囲み、値中の `"` は `""` と記述します。

```csv
"right, correct",正しい,形容詞,
quote,"彼は""はい""と言った",例文,
multiline,"1行目
2行目",例文,
```

閉じていない引用符はエラーとなり、途中までのデータは登録しません。

## 言語指定

CSV自体には言語コード列を持ちません。取り込み画面で単語帳の言語を英語または中国語から選びます。この設定をTTSの言語選択に使用します。

## エクスポート

Android版・macOS版とも4列をUTF-8で出力し、必要なフィールドを自動的に引用します。学習回数や直近の正誤はCSVには含めません。成績を含めて移行する場合はJSONセーブデータを使用します。
