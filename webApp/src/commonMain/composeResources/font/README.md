# Tango Pro Unicode Web font

`tango_pro_unicode.ttf` is generated by `scripts/build_web_unicode_font.py`.
It combines the Simplified Chinese/Japanese coverage already required by Tango
pro with extended Latin characters and common mathematical/general symbols.
This prevents valid UTF-8 CSV text such as `消える（≒ disappear）`, French, and
Portuguese vocabulary from rendering as missing-glyph boxes in Kotlin/Wasm.

The inputs are pinned Google Fonts copies of Noto Sans SC, Noto Sans, Noto Sans
Math, and Noto Sans Symbols 2. All inputs and the generated derivative are
distributed under the SIL Open Font License 1.1 in `OFL.txt`. The derivative
uses the family name `Tango Pro Unicode` and does not use the reserved `Source`
font name.

Regenerate after installing FontTools:

```bash
python3 -m pip install fonttools
python3 scripts/build_web_unicode_font.py
```
