# Tango pro - 単語学習アプリ ユーザーマニュアル (v1.1.0)

「Tango pro」へようこそ！本アプリは、シンプルでパワフルな英単語学習・四択/タイピングクイズゲームアプリです。
ご自身で作成したCSV形式の単語帳をインポートして、効率的に単語を暗記することができます。

---

## v1.1.0 アップデート内容
* **CSV形式で単語帳データをエクスポートする機能を追加**:
  * 選択中の英単語帳データを、UTF-8形式のCSVテキストとしてクリップボードへコピー、またはファイル（.csv）として他アプリやGoogleドライブに保存・共有することができます。
* **出題対象に「おすすめ」モードを追加**:
  * 出題対象に「おすすめ」を追加しました。CSVの先頭から順番に勉強を進められるように考慮し、出題頻度には乱数を用いて、学習進捗状況（未学習/要復習 = 間違えた問題 > うろ覚え > 学習済み）の序列で優先的に出題する画期的なお勧め学習モードです。

---

## 主な機能と使い方

### 1. 進捗状況の確認（ダッシュボード）
* App起動時に表示されるダッシュボードでは、現在の学習グループの進捗状況が一目で分かります。
* **学習進捗度の3段階表示**:
  * **🟢 習得済み (Studied)**: 2回以上学習し、最後に正解した確実な単語
  * **🟡 うろ覚え (Vague)**: 1回のみ学習した、あるいは定着させたい段階の単語
  * **🔴 未学習/要復習 (Unstudied/Review)**: まだ1度も学習していない、あるいは最後に不正解だった単語

### 2. 学習設定（出題学習設定）
アプリで行うクイズの設定を柔軟に変更できます。これらの設定は**アプリを閉じても自動的に保存され、次回もそのまま引き継がれます。**

* **出題形式**: 「4択クイズ」または「タイピングクイズ」を選択できます。
  * *タイピングクイズ選択時は、自動的に「日本語 ➡️ 英語」の出題に固定されます。*
* **出題方向**: 「英語 ➡️ 日本語」または「日本語 ➡️ 英語」を選択できます。
* **出題条件**:
  * すべての単語
  * 未学習の単語のみ
  * 最後を間違えた単語のみ
  * うろ覚え（学習回数1回）の単語のみ
  * 苦手な単語（未学習 ＋ 間違えた単語）
  * 学習済みからランダム
  * カテゴリ・タグ指定
  * 出題範囲指定（開始〜終了）
* **1度に出題される問題数**: 「5問」「10問」「20問」「50問」「全問」から選択できます。

### 3. クイズセッション
* お好みの条件を整えた上で「学習を開始する」をタップすると開始します。
* **音声によるサポート**:
  * 各問題の開始時、または正解時に英語が自動音声（TTS）で読み上げられます（設定でオン/オフ可能）。
  * 英語音声や正誤判定の効果音は、設定ダイアログから個別に音量のスライダーを調整できます。
* 各回答後は正誤が大きく表示され、正解・不正解を独自の軽量ピコピコシンセサイザー音が支援します。

### 4. 設定の調整
ダッシュボード右上のギアアイコン（⚙️）から「アプリの設定」ダイアログを開くことができます。
* **ダークテーマの適用**: 純粋な黒（ピュアブラック）を基調とした、目に優しくコントラストの取れた目に優しいダークモードに切り替えることができます。
* **英語の自動読み上げ (TTS) のオン/オフ**
* **読み上げ音声の音量調整 (0% 〜 100%)**
* **正誤判断効果音のスタイル選択（ピコッ / メロディ / レトロブザー / 消音）**
* **効果音の音量調整 (0% 〜 100%)**
* **一度の学習問題数（デフォルト値）**

## CSVインポート機能について

オリジナル単語帳をインポートして学習することができます。

1. **インポート手順**:
   * ダッシュボード下部またはグループ一覧にある「CSVインポート」ボタンをタップします。
   * インポートしたいCSVファイルを選択し、グループに任意の名前をつけて読み込みます。
   * **不要になったCSV（グループ）は、グループ一覧の削除ボタンからいつでも簡単に削除・クリアが可能です。**

2. **CSVのフォーマットルール**:
   * 日本語や英語の文字化けを防ぐため、必ず **エンコード「UTF-8」** で保存してください。
   * `英語,日本語訳,品詞やカテゴリ（任意）` という1行につき1単語・カンマ区切りの形式です。
     * 例1: `apple,りんご,名詞`
     * 例2: `run,走る,動詞`
     * 例3: `desk,机` （品詞/タグは省略可能）
