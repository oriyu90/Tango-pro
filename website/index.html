自分のCSVが、
続けられる単語帳になる。

Tango proは、手元の単語リストを4択・タイピング・読み上げで学べる単語帳アプリです。登録なしで、学習記録は端末の中に保存されます。

Android APK macOS DMG

標準17冊。自作CSVは最大10万レコード。進捗は単語帳ごとに積み上がります。

覚えるまでの流れを、ひとつの場所に。

単語帳を用意するところから、出題、復習、次の周回まで。学習方法は細かく選べますが、毎日の画面は必要な情報だけにできます。

17 BOOKS
すぐ始められる
中国語基本単語と、Lv.1〜Lv.8の英単語・英熟語を標準搭載。もちろん、自分のCSVもファイルやテキストから追加できます。
2 MODES
4択とタイピング
出題方向、タグ、範囲、問題数を単語帳ごとに保存。英語・中国語・フランス語・ポルトガル語の読み上げにも対応します。
4 SIZES
読める文字サイズ
問題文と4択を、小・標準・大・特大から選択。長い選択肢はボタンの高さが増え、2〜3行でも読み切れます。
∞ ROUNDS
周回が見える
全単語を一度学ぶと2周目へ。2〜4周目は配色も変わり、5周目以降も周回数をそのまま確認できます。

集中したい日は、シンプルモード。

「選択中」は残したまま、学習進捗をバーと%だけに整理。出題設定は必要なときだけ開き、学習開始ボタンはいつでも見える位置に置きます。

Tango pro v2.0.0

GPL-3.0で公開している無料のオープンソースアプリです。配布ファイルとSHA-256はGitHub Releaseで確認できます。

Android

既公開版と互換の証明書で署名したAPK。versionCode 6。

macOS

Apple Silicon／Intel対応のuniversal DMG。macOS 13以降。

DMGを入手

Androidへインストール

  1. 1公式APKをAndroid端末へダウンロードします。
  2. 2通知または「ファイル」アプリからTango-pro-2.0.0-android.apkを開きます。
  3. 3提供元からのインストール許可を求められた場合は、警告とファイル名を確認してから、そのダウンロード元にだけ許可します。
  4. 4「インストール」を選び、完了後にTango proを開きます。端末や地域によって追加の安全確認が表示される場合があります。

Googleの安全に関する案内を確認

macOSへインストール

  1. 1公式DMGをMacへダウンロードして開きます。
  2. 2「Tango pro」を同じ画面の「Applications」へドラッグし、コピー後にDMGを取り出します。
  3. 3アプリケーションフォルダからTango proを一度開きます。開発元を確認できないという警告が出た場合は、いったん閉じます。
  4. 4チェックサムと入手元を確認できた場合だけ、「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選びます。

AppleのGatekeeper案内を確認

安全の確認 macOS版はad-hoc署名・未Notarizeです。ファイル名とSHA-256チェックサムを確認し、不明な配布元から取得したファイルは開かないでください。
